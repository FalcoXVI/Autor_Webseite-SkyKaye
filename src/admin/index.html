The editor is installed and configured for an email login — it just needs to be deployed. Three steps and the author can publish on their own, without a GitHub account.

  1. 01

    Put the site in a GitHub repository and connect that repository to a Netlify site. Nothing to configure here — the editor is already set to git-gateway.

  2. 02

    In the Netlify dashboard enable Identity, set registration to invite only, then enable Identity → Services → Git Gateway. Invite the author by email; he sets his own password from the invitation link.

  3. 03

    He then opens /admin, logs in with his email, and gets the list of posts — write a new one, edit or delete an old one, press Publish. To try it beforehand: run npx decap-server and open this page from localhost.
